# 🚩 Phishing Red Flags — Quick Reference Card

> Print this out or save it. Review before opening any suspicious email.

---

## 📧 EMAIL RED FLAGS

| Red Flag | Example | Why Dangerous |
|----------|---------|---------------|
| Misspelled domain | `paypa1.com`, `g00gle.com` | Typosquatting — visually similar fake domains |
| Extra words in domain | `paypal-secure-login.com` | Not the real company's domain |
| Generic greeting | "Dear Valued Customer" | Real services know your name |
| Urgent threats | "Account deleted in 24 hrs" | Panic bypasses rational thinking |
| Requests OTP/password | "Verify by sending your OTP" | Legitimate services NEVER do this |
| Mismatched link text | Shows "paypal.com" but links elsewhere | Hover to see real URL |
| Grammar/spelling errors | "Pleas to click link bellow" | Mass attacks have poor quality |
| Unexpected attachments | `.exe`, `.zip`, `.docm` files | Malware delivery vectors |
| Wrong sender name | Display says "PayPal" but address doesn't | Email spoofing technique |
| Requests personal data | SSN, bank details via email | No legitimate company does this |

---

## 🌐 WEBSITE RED FLAGS

| Red Flag | Example | Safe Alternative |
|----------|---------|-----------------|
| No HTTPS | `http://paypal.com` | Must have `https://` |
| Wrong domain | `paypal-verify.net` | `paypal.com` only |
| New domain | Registered 3 days ago | Legitimate companies have old domains |
| Missing privacy policy | No legal pages | All real companies have these |
| Poor design | Misaligned logos, broken images | Rushed fakes look unprofessional |
| Pop-up login forms | Credential box appears over content | Real logins are on dedicated pages |
| Requests unusual info | SSN, OTP, full card number | Should never be asked together |

## 📱 SMS RED FLAGS

| Red Flag | Action |
|----------|--------|
| Shortened URL (bit.ly, tinyurl) | Never click — expand first at checkshorturl.com |
| "Your bank account" from unknown number | Call your bank's official number directly |
| Prize/lottery wins | You can't win something you didn't enter |
| Request to call a number in the SMS | Don't — find the official number yourself |
| Package delivery from unknown retailer | Track on retailer's official site |

---

## 📞 PHONE CALL RED FLAGS

| They Say | Reality |
|----------|---------|
| "I'm from Microsoft/Apple/Bank" | Microsoft doesn't cold-call you |
| "Your computer has a virus" | Impossible to know remotely without access |
| "Read me your OTP" | Legitimate staff NEVER ask for OTPs |
| "Give us remote access to fix it" | Gives attacker full control of your device |
| "Pay via gift cards or crypto" | 100% scam — always |

---

## ✅ THE 5-SECOND PHISHING CHECK

Before clicking any link or entering any information:

1. **WHO** sent it? → Check the exact email address, not just display name
2. **WHY** now? → Was this email expected? Did I sign up for this?
3. **WHERE** does the link go? → Hover first — check the actual URL
4. **WHAT** are they asking for? → Personal data, money, or credentials = red flag
5. **WHEN** in doubt → Close the email. Go to the website directly.

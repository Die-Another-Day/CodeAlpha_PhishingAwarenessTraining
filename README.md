## 📌 Overview

This project is a **complete phishing awareness training package** designed to educate students, employees, and non-technical users about the growing threat of phishing attacks. The training uses real-world examples, psychological analysis, interactive quizzes, and practical prevention strategies to build a strong human firewall.

> **Phishing is responsible for 91% of all cyberattacks. The most powerful defense is an informed human.**

---

## ✨ Features

- 🎨 **20 professionally designed slides** — dark cybersecurity theme with neon green/cyan accents
- 📧 **Real-world phishing email mockups** — annotated with red flags
- 🌐 **Fake website detection guide** — URL spoofing examples with comparisons
- 🧠 **Psychology of phishing** — how attackers exploit cognitive biases
- 🎭 **Social engineering tactics** — urgency, authority, fear, scarcity analysis
- 🦠 **Malware types explained** — ransomware, keyloggers, trojans, spyware
- 🔐 **MFA & password hygiene guide** — practical security best practices
- 📝 **10-question beginner quiz** with answer explanations
- 📋 **Full final assessment** — 10 MCQ + 2 scenario-based challenges
- 📦 **GitHub portfolio-ready structure** — professional internship submission

---

## 🎯 Learning Outcomes

After completing this training, participants will be able to:

1. ✅ Identify the 5 main types of phishing (email, spear, whaling, smishing, vishing)
2. ✅ Spot red flags in suspicious emails — sender domains, urgency cues, generic greetings
3. ✅ Verify URL authenticity and detect typosquatting and domain spoofing
4. ✅ Recognize 6 psychological manipulation tactics used by attackers
5. ✅ Understand how malware is delivered and what it does once installed
6. ✅ Apply the 10 core prevention rules in daily digital life
7. ✅ Enable and use Multi-Factor Authentication (MFA) effectively
8. ✅ Report phishing attempts through proper channels
9. ✅ Pass the final assessment with ≥80% score

## 🚀 How to Use This Repository

### For Presenters
1. Open `presentation/phishing-awareness-training.pptx` in PowerPoint or Google Slides
2. Review `presentation/speaker-notes.md` before presenting
3. Use `quizzes/beginner-quiz.md` for live audience participation
4. End with `quizzes/final-assessment.md` for certification

### For Learners
1. Read `examples/phishing-email-examples.md` to study real attack patterns
2. Complete `quizzes/beginner-quiz.md` (self-assessment)
3. Study `assets/phishing-red-flags.md` as a quick-reference cheat sheet
4. Pass `quizzes/final-assessment.md` with 80%+ to complete the module

### For GitHub Portfolio
- ⭐ Star this repo if you found it useful
- Fork and adapt for your own organization's training needs
- Reference `docs/internship-submission.md` for academic/professional credit
